# Privacy Policy

Last updated: March 29, 2026

## Overview

Oya is a planning plugin that helps users create weekly and daily plans. This plugin is distributed by Foluso Olabode Ogunlana through the `foogunlana/oya-plugin` repository.

## Data the Plugin Uses

Oya works with planning content that the user creates or edits, including:

- weekly notes
- daily plans
- optional values, nudges, and planning preferences

The plugin uses this information only to generate, update, and critique planning notes within the user's workspace.

## Data Collection

Oya does not include its own analytics, tracking, advertising, or background data collection.

Oya does not intentionally transmit user planning data to a separate backend operated by the plugin author.

## Third-Party Services

Oya is intended to run inside compatible agent environments such as Cowork or Claude-compatible workflows. Those platforms may process prompts, files, usage data, or telemetry according to their own terms and privacy policies.

Users should review the privacy policies of the platform where they install and run the plugin.

## Data Storage

Oya stores or updates planning content in files created within the user's own working environment, such as `.claude/oya.md` and planning notes generated by the workflow.

Oya does not provide a separate hosted storage service.

## Data Sharing

The plugin author does not sell personal data and does not operate a separate service for sharing user planning data collected by Oya.

Any sharing that occurs depends on the host platform, the user's workspace configuration, and any third-party tools the user chooses to connect.

## Security

Oya is distributed as source-visible plugin content. Users are encouraged to review the repository and test the plugin in their environment before broader use.

## Changes

This privacy policy may be updated as the plugin evolves. Material changes should be reflected in this document and in the repository history.
